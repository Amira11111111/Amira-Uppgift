ABOUT THE GAME

"Get Keke Out The Club" is an interactive Club-themed game controlled by sound. A contact microphone picks up the sound the user makes, and the louder the sound, the further the character moves to the right. Players must navigate through a colourful nightclub, avoid obstacles such as exes, spilled drinks and bottles, and try to escape the club without crashing. Try it out yourself here!

I am Amira Smith, one of the creators behind the game together with Anahi. As a creator, I like to create fun and engaging experiences. I like to try new things, and I try to contribute in developing experiences/designs that have an exciting concept that leaves you wanting for more. I like to keep it simple but intruiging.

We used Claude AI to help us code and understand functions and statements. We also used Claude to help us with the layout of the game, and to help us with javascript code we were unfamiliar with such as the game loops, graphics and fetching the sound/voume and turning it into movement. An example of one prompt would be "Make the character have a default position to the left when the game starts". We are the minds behind this game. Everything we have prompted has had a meaning and been thought throughout. We ourselves had a moodboard, a theme we wanted to make a reality. Even the main function (moving via sound),was our idea. We have also coded a bit by ourselves, and done some adjustments in the HTML and CSS codes based off our visualizations. We did actively test the browser after Claude helpes us, and sometimes AI´s code could contradict ours, and errors would occur. Reviewing our own code with Claude also releaved a logic error in our start button.
